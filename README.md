# automation

Репозиторий с лабораторными работами по автоматизации задач в Linux с помощью shell-скриптов, Python, cron, Docker, Jenkins и Ansible.

## Структура

| Работа | Тема                                   | Папка              |
|--------|----------------------------------------|--------------------|
| lab01 | Скрипт резервного копирования директории | [lab01/](lab01/) |
| lab02 | Клиент Web API курсов валют: курс на заданную дату с сохранением в JSON | [lab02/](lab02/) |
| lab03 | Расписание cron для скрипта курсов валют в Docker-контейнере | [lab03/](lab03/) |
| lab04 | Jenkins: контроллер и SSH-агент в Docker Compose, конвейер для PHP-проекта с PHPUnit | [lab04/](lab04/) |
| lab05 | Ansible: настройка тестового сервера и развёртывание isbn-tools из трёх конвейеров Jenkins | [lab05/](lab05/) |
